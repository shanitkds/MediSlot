# Backend

Express API for the MediSlot Doctor Appointment & Medical Slot Booking Management System.

```bash
copy .env.example .env
npm install
npm run seed
npm run dev
```

- Port: `5000`
- API prefix: `/api/v1`
- Health: `GET /health`

See `PROJECT_DETAILS.md` for complete architecture, endpoints, and live work log.
See `../docs/backend.md` and `../docs/api.md`.
